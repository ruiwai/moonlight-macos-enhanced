# Control ball visibility and input (macOS manual check)

1. In a borderless stream, press and hold the visible ball **without moving**.
   Hide it with `Ctrl` + `Option` + `G`, then release the mouse. Control Center
   must not open. Click where the ball was: the click should reach the host.
2. Enter fullscreen on the same host. The ball should remain hidden. Show it
   with the shortcut and click it once; Control Center should open on that first
   click. Return to a regular titled window: the ball should not appear there.
3. Repeat the hide/release/show sequence during a drag. On a direct-touch Mac
   also try a pan. The old gesture must not move or activate the re-shown ball;
   a new drag should work normally.
